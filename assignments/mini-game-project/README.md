# 📘 Atividade: Mini Game Project

## 🎯 Objective

Build a small interactive game in Python using loops, conditionals, classes, and event handling. Students will practice organizing code into reusable pieces while creating a playable project with clear rules and feedback.

## 📝 Tasks

### 🛠️ Build the game screen and player

#### Descrição

Create a simple game window and a player-controlled character that can move around the screen. Use the starter code as a foundation and add the visual and interactive elements needed for a playable experience.

#### Requisitos
O programa concluído deve:

- Open a game window with a clear title and fixed screen size.
- Create a player character that can move using keyboard input.
- Add a background and at least one visible game object besides the player.
- Keep the game running smoothly with a frame loop and a clock.
- Close the game correctly when the user exits the window.

### 🛠️ Add gameplay rules and scoring

#### Descrição

Expand the game by adding challenge elements, scoring, and a win or lose condition. The goal is to make the game feel complete and easy to understand while keeping the logic readable.

#### Requisitos
O programa concluído deve:

- Include a clear objective for the player, such as collecting items, avoiding enemies, or reaching a target.
- Track score or progress during the game.
- Detect collisions or interactions between the player and game objects.
- Show a message or update the screen when the player wins or loses.
- Restart or end the game gracefully after the outcome is reached.
- Use functions or classes to organize the game logic in a clean structure.

Exemplo de fluxo do jogo:

```text
Player moves with arrow keys
Collect 5 stars to win
If an enemy touches the player, the game ends
Score updates on each collected item
```
